# arknova-leaderboard

A responsive and live-updated leaderboard for all-time BGA peak elo in Ark Nova. Dwarvintime would've led this ranking.

The static page reads the `Masters` worksheet from Google Sheet
`1NG3FPP70riMzhHPJ6Suz30bhJxUocFd_rKDKxn0kZbM`. The optional “Include selected
Experts” control adds rows from the workbook's `Experts` worksheet. Both sheets
use country in column B, BGA name in C, Peak Elo in F, Peak-Elo date in G, best
season-ending Arena rank in I, BGA player ID in K, and Peak-Elo table ID in M.
Alternate accounts marked in column D are excluded.

100% vibe coding, 0% comprehension. Check out the result here: https://pr0paganda-panda.github.io/arknova-leaderboard/leaderboard.html
